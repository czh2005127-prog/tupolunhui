- 修改游戏逻辑前必须先阅读与改动相关的章节。
- 当前代码与本文档冲突时，以本文档为准，并将代码修正至一致。

- 规则存在歧义且不同解释会明显影响玩法时，先记录为“待确认”，不得擅自引入新机制。
- 纯 UI 表现修改不得改变本文档规定的底层游戏结果。

## 1. 世界观

### 背景

玩家在古玩市场淘到一个木盒，打开后被吸入盒中世界。盒子里封存着一整套被诅咒的卡牌和骰子——每一张卡都是一个活人被吸收后同化而成的囚徒。木盒不断吸收各世界的玩家，将他们做成新的卡牌。

### 目标

击败所有卡牌对手 → 击败骰子之神 → 逃出盒子。失败则被同化，变成盒子里的下一张卡。

### 四层氛围

| 层 | 名称 | 对手来源 | 变质规则 |
|----|------|---------|---------|
| 1 | 破烂后院 | 刚被吸进来的普通人 | 标准 5d6，无特殊规则 |
| 2 | 地下赌场 | 老玩家，已适应盒子规则 | 每人一颗暗骰（自己看不到） |
| 3 | 黑帮私局 | 差点逃出去的旧挑战者 | 传染骰——叫到指定点数必须跟叫 |
| 4 | 终极赌场 | 骰子之神及其近卫 | 禁忌点数——叫到者立即扣除 1 颗骰子 |

## 2. 核心循环

### 一局完整流程

```
主菜单 → 第1层随机节点（2战斗＋1商店＋1事件）→ Boss → 第2层 ...
```

### 单层线性序列

每层固定共 5 个节点：普通战 ×2、商店 ×1、事件 ×1、Boss ×1。Boss 永远位于最后；前四个节点随机排列，但商店之前必须至少完成一次普通战。每层节点顺序在进入该层时生成并保存，继续游戏不得重新随机。

- 每个节点结束后自动进入下一个，无地图分支
- 节点间 1.5s 滑行过渡 + 氛围文字描述

### 单场对局结构

```
进入节点 → 双牌堆抽卡 → 翻开对手卡
    → (如抽到未知卡: 直接进入高难度对局)
    → 骰子对局(1v2 或 Boss 1v3)
    → 结算 → 发放奖励 → 进入本层下一个节点
```

- 进入每场战斗前建立“战斗入口快照”，内容包括金币、同化及诅咒状态、道具、碎片和所有下一战修正。
- 暂退或重新加载时恢复战斗入口快照，并使用进入该战斗时已经抽定的同一组对手重新开始，不保留战斗中消耗的道具、获得的金币、骰子变化或感染变化。
- 战斗入口同时保存随机种子；相同操作顺序必须得到相同的开局投骰、AI投骰和随机技能目标，不能通过反复退出重进刷新有利结果。

### Boss 战、Boss 技能与碎片

- 普通战中抽到的卡牌只使用该角色原有技能，不附加 Boss 技能。
- Boss 战牌堆 B 抽到并由玩家选中的卡牌是本场 Boss 主体。该卡保留原角色技能，并额外获得一条属于该卡的 Boss 技能。
- 击败前三层 Boss 后，玩家获得与本场 Boss 主体卡对应的 Boss 碎片；抽到哪张 Boss 卡，就获得哪张卡的碎片。
- 第四层骰子之神不提供碎片；击败骰子之神后直接完成本盘并进入通关结算。
- Boss 碎片构成玩家的盘内成长内容；碎片技能只在当前一盘内生效，不写入永久角色属性。
- 玩家最多保留 2 个 Boss 碎片。获得第三个不同碎片时，必须选择替换一个已有碎片，或者丢弃新碎片。
- 同名碎片不叠加；再次获得已经持有的碎片时，保持原碎片，不占用新槽位，也不触发替换。

#### Boss 技能与对应碎片

| Boss 主体 | 追加 Boss 技能 | 击败后获得的碎片能力 |
|-----------|----------------|---------------------|
| 回收商 | **强制回收**：每轮质疑结算后若仍存活，从本轮失败者处夺取 1 颗骰子 | **回收碎片**：玩家质疑成功时，从被质疑者处夺取 1 颗骰子 |
| 幸运儿 | **绝对幸运**：每轮投骰后，将自己的至多 2 颗非①骰变为① | **幸运碎片**：每轮投骰后随机选取自己的至多 2 颗骰子，每颗有 50% 概率改为①；未触发时保持原投骰结果 |
| 裁判长 | **终审豁免**：每局第一次因质疑结算本应被淘汰时免疫该次淘汰 | **裁判碎片**：每局第一次质疑失败不产生同化 |
| 镜面技师 | **增殖镜像**：每轮复制玩家骰子后，再增加 1 颗与玩家当前最多点数相同的骰子 | **镜面碎片**：每局第一轮复制自己随机 1 颗骰子，永久增加到本局骰杯中 |
| 赌桌幽灵 | **亡者席位**：开局为另外两名对手各提供 1 次伤害免疫；幽灵被淘汰后未消耗的免疫立即消失 | **幽灵碎片**：抵挡玩家下一次同化；抵挡成功后该碎片立即消失 |
| 同盟 OLED | **公开审判**：每轮随机公开玩家 2 颗普通骰子的真实点数，所有对手都能利用该情报 | **同盟碎片**：每轮随机选择一名存活对手，向玩家公开其 2 颗普通骰子 |
| 赌场主 | **黑幕抽水**：开局额外为全场增加 2 颗暗骰，Boss 可以看见自己的全部暗骰 | **赌场碎片**：每局第一轮为玩家增加 1 颗只有玩家自己可见的额外骰子 |
| 算法先知 | **收敛预言**：每轮重算结束后，将自己的 2 颗骰子改为当前最多的自身点数 | **先知碎片**：每轮自动重摇自己点数最低且不为①的一颗骰子；若新结果更低则保留原点数 |
| 庄家 | **加注开盘**：在原本 8 颗骰子的基础上额外 +1，以 9 颗骰子开局 | **庄家碎片**：玩家每局开局额外获得 1 颗骰子 |
| 骰子之神 HOLO | **双重禁忌**：每轮同时存在 2 个不同的禁忌点数，叫到任意一个都会扣除 1 颗骰子 | **无碎片** |

- “普通骰子”不包括暗骰；查看效果不得把暗骰公开。
- 碎片增加、复制或改变的骰子仍遵守本层万能骰、传染点数和禁忌点数规则。

#### 碎片与道具功能边界

- 幸运碎片与虚张声势都会制造①；前者每轮概率触发，后者主动消耗，不重复结算。
- 同盟碎片与透屏、热感视觉、大小判都提供情报；碎片随机持续，道具主动定向，不视为重复。
- 庄家、赌场、镜面碎片与加骰、克隆骰都可能增加骰子；碎片时机固定，道具由玩家选择时机，不视为重复。
- 先知碎片与重摇石、全重摇均涉及重投；先知只自动处理最低非①骰并保留较优结果，道具主动重投，不得互相触发。

## 3. 骰子规则

### 对局术语

- **一轮**：从一次叫牌/质疑过程开始，到有人质疑并完成开骰结算为止。
- **一局**：从一组对手进入骰子战斗开始，到玩家或全部对手被淘汰为止；一局包含若干轮。
- **一盘**：从新一轮爬塔开始，到击败最终 Boss 或玩家完全同化结束为止；一盘包含多个节点与多局战斗。

### 基础规则

- 每人 5 颗 d6
- ① 为万能骰子（可当任何点数）
- 叫牌时叫 ① 则 ① 锁定，不再万能
- 每轮首次叫牌的最低数量 = 当前存活人数 + 1；后续可加数量或同数量加点数
- 无斋/飞概念

### 操作

| 操作 | 说明 |
|------|------|
| 加注 | 增加数量，或同数量换更高点数 |
| 质疑 | 质疑上家的叫牌。开骰验证——质疑成功 = 被质疑者感染，质疑失败 = 质疑者感染 |

### 回合顺序

- 庄家在场 → 每轮都由庄家先叫
- 庄家不在场 → 随机先叫
- 之后顺时针轮转

### 骰子数量

无上限约束。卡牌技能可自由增减骰子数。

- 任意角色的骰子数量降为 0 时，该角色立即被淘汰。
- 主动“夺取/吞噬骰子”的效果不能夺走目标最后 1 颗骰子；目标仅剩 1 颗时该效果不能使用。
- 同一次结算中多个夺取效果可以叠加，但最多只夺到目标剩余 1 颗骰子为止。禁忌点数等直接扣骰效果不受此保护，可以把角色扣至 0 并触发淘汰。

### 全卡表

#### 普通卡（#1-4）

**#1 · 瘸腿老杰克 —「偷窥」**
每局 1 次，看玩家 1 颗骰子。
| Lv.1 | 看 2 颗 |
| Lv.2 | 看 2 颗，本局可再用一次 |
| Lv.3 | 看 3 颗，可再用一次，看到的骰子对全场公开 |

“对全场公开”表示所有仍存活的 AI 都获得这些骰子的真实情报，并可用于后续叫牌与质疑判断。

**#2 · 锈铁战士 —「意志依存」**
被淘汰时随机给一个存活者 +1 颗 ①。
| Lv.1 | 给两个存活者各 +1 ① |
| Lv.2 | 给两个 + 淘汰前让一个对手 −1 骰子 |
| Lv.3 | 给所有存活者各 +1 ① + 对手 −1 骰子 |

**#3 · 电池小子 —「备用电源」**
第一次被击败免死，回 1 HP。
| Lv.1 | 免死 2 次 |
| Lv.2 | 免死 3 次 |
| Lv.3 | 免死 3 次，每次免死后 +1 骰子 |

**#4 · 信号噪音 —「干扰」**
开局随机禁用玩家 1 个道具。本局生效。
| Lv.1 | 禁用 2 个 |
| Lv.2 | 禁用 3 个 |
| Lv.3 | 禁用 4 个 |

#### 稀有卡（#5-7）

**#5 · 独眼龙 LCD —「锁定」**
每局 1 次，删掉 1 个点数，本局没人能叫。
| Lv.1 | 删 2 个点数 |
| Lv.2 | 删 3 个点数 |
| Lv.3 | 删 3 个点数，被删点数若出现在任何人骰子上 → 随机暴露 1 颗 |

Lv.3 暴露的是一颗原本对其他玩家不可见的普通投骰子，不限于暗骰；暴露后全场知道其点数。

**#6 · 双面人 —「反转骰」** （不升级）
每颗骰子正反面通用，⑥ = 万能骰。

**#7 · 侍从长 —「军械库」**
开局获得 3 个随机道具。
| Lv.1 | 5 个道具 |
| Lv.2 | 5 个道具，保底 1 件稀有以上 |
| Lv.3 | 6 个道具，保底 2 件稀有以上 |

侍从长只会获得并使用作用于自身的战斗道具，不会获得需要指定其他角色为目标的道具，也不会使用金币结算类道具。

#### 史诗卡（#8-12）

**#8 · 回收商 —「捡骰」**
有人开失败时他 +1 骰子。
| Lv.1 | +2 骰子 |
| Lv.2 | +2 骰子，被质疑者也 −1（回收商吸走） |
| Lv.3 | +2，吸 1，每轮结束自动 +1 |

**#9 · 幸运儿 —「骰神眷顾」**
骰子里永远多 1 个 ①。
| Lv.1 | 多 2 个 ① |
| Lv.2 | 多 3 个 ① |
| Lv.3 | 多 3 个，他的 ① 只有他自己能当万能骰 |

**#10 · 裁判长 —「强制执行」**
裁判长可指定一个仍存活的对手立即行动；目标在当时局面中自行选择质疑或继续叫牌。没有上家叫牌时，目标只能叫牌。
| 默认 / Lv.1 | 每场对局最多使用 1 次 |
| Lv.2 | 每场对局最多使用 2 次 |
| Lv.3 | 每场对局最多使用 3 次 |

**#11 · 镜面技师 —「镜像」** （不升级）
骰子完全复制玩家的骰子。玩家使用只作用于自身的战斗道具时，他也获得相同类型的自身效果；目标型、情报型、金币结算型道具不复制。

**#12 · 赌桌幽灵 —「附身」** （最高 Lv.2）
淘汰后附身 1 个对手（对手 +1 骰子 + 获得幽灵技能）。
| Lv.1 | 附身 2 个对手 |
| Lv.2 | 附身 2 个，被附身者 1 轮内无法被质疑 |

#### 传说卡（#13-16）

**#13 · 同盟 OLED —「全知」** （最高 Lv.1）
知道 n−2 人骰子（n=存活人数）。被选中者收到通知。
| Lv.1 | 知道 n−1 人 |

**#14 · 赌场主 —「暗骰加码」**
每人 +1 颗暗骰（他自己也看不到）。
| Lv.1 | 每人 +2 |
| Lv.2 | +2，他自己能看到自己的 |
| Lv.3 | +3，他自己全能看到 |

**#15 · 算法先知 —「重算」** （最高 Lv.2）
每轮可重掷任意颗骰子。
| Lv.1 | 重掷后额外 +1 骰子 |
| Lv.2 | 重掷 +1，每轮可重掷 2 次 |

**#16 · 庄家 —「开盘」** （不升级）
每轮都由庄家先叫；庄家在整场对局开局时拥有 8 颗骰子。

若同场出现两张庄家，两名庄家都以 8 颗骰子开局；每轮开始时从仍存活的庄家中随机选择一名起叫。

#### 创世卡（#17）

**#17 · 骰子之神 HOLO —「禁忌变更」** （不升级）
每轮随机更换 1 个禁忌点数。

#### 未知卡（#18-20）

**#18 · 镜像 —「广播」** （不升级）
每轮开始公布全场最多的 1 个点数。

**#19 · 混沌 —「乱码」** （不升级）
叫牌显示随机篡改——玩家看到的数量和点数可能与实际不同。

- 每场混合牌堆固定展示 5 张候选：3 张当前层已解锁常规卡，加 2 张不同的随机未知卡。
- 玩家选择 2 张，因此形成三类组合：常规＋常规、常规＋未知、未知＋未知。
- 若已解锁常规卡不足 3 张，允许重复补足，但同一张卡最多出现 2 张。

### 未知卡触发

抽到未知卡 → 黑紫脉冲特效（2s） → 直接进入对局，不弹出「迎战 / 回避」确认。

- 未知卡对局按高难度精英战结算，并发放对应高奖励。
- 未知卡不可回避。
- 选择 1 张未知卡：普通战奖励外追加 1 件精英道具和 2 锈蚀点。
- 选择 2 张未知卡：金币额外 ×1.25，保底追加 1 件稀有道具和 4 锈蚀点；道具只发一次。

## 8. 锈蚀契约·升级

### 经验、解锁与难度

- 经验等级与卡牌/道具解锁系统保留；卡池只能使用已经解锁的卡牌。
- 初始在普通、稀有、史诗、传说四个主要牌池中各解锁 3 张卡；后续经验等级逐步补齐剩余卡牌和道具。
- 不提供独立困难模式或困难模式数值倍率。
- 对手难度提升仅来自玩家在锈蚀工坊购买并启用的卡牌升级等级。
- 卡牌强化最高不超过 Lv.3，并遵守全卡表中已有的逐卡上限：赌桌幽灵与算法先知最高 Lv.2，同盟 OLED 最高 Lv.1；原本注明“不升级”的卡牌仍不参与锈蚀强化。
- 购买 Lv.1、Lv.2、Lv.3 的本次费用分别为 1、2、3 锈蚀点，与稀有度无关；不存在统一追加开局骰子的 Lv.4/Lv.5 强化。
- 旧存档中已经购买的 Lv.4/Lv.5 会自动降至该卡当前最高等级，并按被移除等级原费用返还锈蚀点；迁移只执行一次。
- 战斗奖励倍率按照本场实际出现对手的强化等级取平均值：Lv.0 = 1.00、Lv.1 = 1.05、Lv.2 = 1.12、Lv.3 = 1.22。
- 奖励倍率作用于该场战斗的金币与 XP，分别向下取整且至少保留原始奖励；道具数量、道具稀有度和锈蚀点不参与倍率，避免奖励循环失控。

### 禁忌规则模式

- 玩家第一次击败骰子之神并完成整盘后永久解锁。
- 开始新盘前可以自由勾选多条禁忌规则；规则效果与奖励倍率叠加，当前选择写入永久设置并在新盘开始时锁定。
- 当前规则：
  1. **禁忌蔓延**：所有层每轮都有 1 个禁忌点数，叫到者扣 1 骰；战斗金币与 XP +20%。第四层骰子之神仍使用双重禁忌，不再额外增加第三个。
  2. **高压开盘**：每轮最低起叫数量在“存活人数＋1”基础上再 +1；战斗金币与 XP +15%。
  3. **缺口骰杯**：玩家每场只以 4 颗基础骰子开局；战斗金币与 XP +25%。
- 奖励加成与卡牌升级倍率相乘；未知双精英的金币倍率最后计算。

### AI难度曲线

- 第1层：只使用己方骰子和基础概率，偶尔出现保守误判，不读取玩家历史习惯。
- 第2层：正确利用已公开骰子、暗骰数量和基础桌面规则，减少无依据的大幅加注。
- 第3层：开始记录玩家最近的真假叫牌与质疑结果，并依据玩家虚张声势倾向调整质疑阈值。
- 第4层：完整利用已知信息、玩家历史、存活状态、禁忌点数和卡牌性格；只有证据充足时才进行大幅加注。
- 难度提升只提高信息利用率和决策质量，不允许AI读取规则未公开的玩家骰子。

## 11. 教程

嵌入第 1 轮游戏中。浮动文字指引，不弹窗。

| 节 | 教学内容 | 保证赢？ |
|:--:|------|:--:|
| 普通战 ① | 骰子规则 + 叫牌操作 + 第一次质疑 | 仅保证教学质疑成功，不保证整场胜利 |
| 首个商店 | 商店、刷新与店内赌桌 | — |
| 后续普通战 | 对手技能 | 否 |
| Boss | 3 卡 Boss 战提示 | 否 |

- 半同化首次触发时浮字说明
- 设置里可勾选「跳过教程」
- 完成对应教学操作后关闭该条浮字；第二盘起不再播放强制教学

### 推荐实施方案：一场战斗内学会

教程只在玩家第一次开始游戏时运行，目标是在 3～5 分钟内让玩家实际完成一次“看骰 → 叫牌 → 判断 → 质疑”，不使用长篇弹窗。

1. **看自己的骰子**：用一句浮字说明“①可以代替其他点数”，高亮玩家骰子 2 秒。
2. **第一次叫牌**：只高亮数量、点数和确认按钮，并提示“你在猜全桌一共有多少颗这个点数”；默认放在合法最低起叫值。
3. **观察对手加注**：对手进行一次预设的温和加注，浮字说明“后续必须增加数量，或数量不变时提高点数”。
4. **第一次质疑**：安排对手给出必定为假的叫牌，高亮“质疑”，玩家点击后保证成功，让玩家亲自看到开骰与感染结算。
5. **自由结束首战**：取消脚本控制，让玩家用正常规则完成剩余战斗；首战只保证教学质疑成功，不强制整场必胜。
6. **首个商店**：只显示一句“金币购买一次性道具，最多携带3个”，高亮一个买得起的普通道具。
7. **第二场战斗**：首次触发敌人技能时，用一行浮字解释“卡牌会修改基础规则”，之后不再打断。
8. **首次半同化**：在三选一界面上直接展示能力与代价，不额外弹说明窗口。

- 每条教学提示不超过两行；完成对应操作后立即消失。
- 玩家任何时候都能在设置中关闭教程；关闭后本盘不再出现教学脚本。
- 从第二盘开始永久关闭强制教学，只保留首次遇到新规则时的短提示。

## 12. 同化与死亡

| 次数 | 状态 | 效果 |
|------|------|------|
| 第 1 次 | 半同化 | 画面边缘出现卡牌纹理，继续战斗 |
| 第 2 次 | 完全同化 | 游戏结束。回到主菜单。点数保留。 |

- 半同化状态跨局累积
- 仅能通过净化芯片或事件清除
- 没有二命，没有继承机制

### 半同化诅咒能力

玩家第一次同化并进入半同化时，从以下三种诅咒能力中选择一种。能力随半同化状态跨局保留；通过净化芯片或事件恢复、清除半同化时，已选择的诅咒能力同时消失。

1. **双重万能**：自己的 ③ 也可作为万能骰；持有该能力时，玩家不能叫 ③，也不能叫 ①。
2. **增殖代价**：每轮开始额外增加 1 颗骰子，每场最多因此增加 3 颗；随后随机选择自己的一颗 ①，将其随机变为 ②～⑥。若当前没有 ①，则本轮只增加骰子。
3. **吞噬质疑**：玩家质疑成功时，从被质疑者处吞噬至多 2 颗骰子并占为己有；与回收碎片叠加时可再多吞 1 颗，但目标始终至少保留 1 颗。玩家质疑失败时立即完全同化，本盘结束。

- 半同化诅咒不是额外生命；玩家再次同化仍会立即完全同化。
- “恢复”仅指净化芯片或事件清除半同化，不包括普通的骰子增加、免疫或其他卡牌技能。
