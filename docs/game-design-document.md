## 1. 世界观

### 背景

玩家在古玩市场淘到一个木盒，打开后被吸入盒中世界。盒子里封存着一整套被诅咒的卡牌和骰子——每一张卡都是一个活人被吸收后同化而成的囚徒。木盒不断吸收各世界的玩家，将他们做成新的卡牌。

### 目标

击败所有卡牌对手 → 击败骰子之神 → 逃出盒子。失败则被同化，变成盒子里的下一张卡。

### 四层氛围

| 层 | 名称 | 对手来源 | 变质规则 |
|----|------|---------|---------|
| 1 | 破烂后院 | 刚被吸进来的普通人 | 标准 5d6，无特殊规则 |
| 2 | 地下赌场 | 老玩家，已适应盒子规则 | 每人一颗暗骰（自己看不到） |
| 3 | 黑帮私局 | 差点逃出去的旧挑战者 | 传染骰——叫到指定点数必须跟叫 |
| 4 | 终极赌场 | 骰子之神及其近卫 | 禁忌点数——叫到者立即扣除 1 颗骰子 |

## 2. 核心循环

### 一局完整流程

```
主菜单 → 第1层: 抽卡 → 普通战 → 商店 → 普通战 → 商店 → Boss → 第2层 ...
```

### 单层线性序列

| 层 | 节点序列 |
|----|---------|
| 1 | 普通战 → 商店 → 普通战 → 商店 → Boss |
| 2 | 普通战 → 商店 → 普通战 → 商店 → 事件 → Boss |
| 3 | 普通战 → 商店 → 普通战 → 商店 → 普通战 → 商店 → Boss |
| 4 | 普通战 → 商店 → 普通战 → 商店 → 普通战 → 商店 → 普通战 → Boss |

- 每个节点结束后自动进入下一个，无地图分支
- 节点间 1.5s 滑行过渡 + 氛围文字描述

### 单场对局结构

```
进入节点 → 双牌堆抽卡 → 翻开对手卡
    → (如抽到未知卡: 直接进入高难度对局)
    → 骰子对局(1v2 或 Boss 1v3)
    → 结算 → 发放奖励 → 进入商店(普通战后)
```

- 从存档继续时恢复到当前战斗节点，但不保存战斗现场；玩家重新抽卡并从该场战斗开局重新挑战。

### Boss 战、Boss 技能与碎片

- 普通战中抽到的卡牌只使用该角色原有技能，不附加 Boss 技能。
- Boss 战牌堆 B 抽到并由玩家选中的卡牌是本场 Boss 主体。该卡保留原角色技能，并额外获得一条属于该卡的 Boss 技能。
- 击败 Boss 后，玩家获得与本场 Boss 主体卡对应的 Boss 碎片；抽到哪张 Boss 卡，就获得哪张卡的碎片。
- Boss 碎片构成玩家的盘内成长内容；碎片技能只在当前一盘内生效，不写入永久角色属性。
- 玩家最多保留 2 个 Boss 碎片。获得第三个不同碎片时，必须选择替换一个已有碎片，或者丢弃新碎片。
- 同名碎片不叠加；再次获得已经持有的碎片时，保持原碎片，不占用新槽位，也不触发替换。

#### Boss 技能与对应碎片

| Boss 主体 | 追加 Boss 技能 | 击败后获得的碎片能力 |
|-----------|----------------|---------------------|
| 回收商 | **强制回收**：每轮质疑结算后若仍存活，从本轮失败者处夺取 1 颗骰子 | **回收碎片**：玩家质疑成功时，从被质疑者处夺取 1 颗骰子 |
| 幸运儿 | **绝对幸运**：每轮投骰后，将自己的至多 2 颗非①骰变为① | **幸运碎片**：每轮投骰后，将自己随机 1 颗非①骰变为① |
| 裁判长 | **终审豁免**：每局第一次因质疑结算本应被淘汰时免疫该次淘汰 | **裁判碎片**：每局第一次质疑失败不产生同化 |
| 镜面技师 | **增殖镜像**：每轮复制玩家骰子后，再增加 1 颗与玩家当前最多点数相同的骰子 | **镜面碎片**：每局第一轮复制自己随机 1 颗骰子，永久增加到本局骰杯中 |
| 赌桌幽灵 | **亡者席位**：开局为另外两名对手各提供 1 次伤害免疫；幽灵被淘汰后未消耗的免疫立即消失 | **幽灵碎片**：每局第一次受到同化时免疫该次同化 |
| 同盟 OLED | **公开审判**：每轮随机公开玩家 2 颗普通骰子的真实点数，所有对手都能利用该情报 | **同盟碎片**：每轮随机查看一名存活对手的 1 颗普通骰子 |
| 赌场主 | **黑幕抽水**：开局额外为全场增加 2 颗暗骰，Boss 可以看见自己的全部暗骰 | **赌场碎片**：每局第一轮为玩家增加 1 颗只有玩家自己可见的额外骰子 |
| 算法先知 | **收敛预言**：每轮重算结束后，将自己的 2 颗骰子改为当前最多的自身点数 | **先知碎片**：每轮自动重摇自己点数最低且不为①的一颗骰子；若新结果更低则保留原点数 |
| 庄家 | **高额底池**：Boss 以 10 颗骰子开局；其存活时每轮最低起叫数量额外 +2 | **庄家碎片**：玩家每局开局额外获得 1 颗骰子 |
| 骰子之神 HOLO | **双重禁忌**：每轮同时存在 2 个不同的禁忌点数，叫到任意一个都会扣除 1 颗骰子 | **破界碎片**：获得时立即额外得到 3 锈蚀点和 50 XP，作为击破木盒规则的最终奖励 |

- “普通骰子”不包括暗骰；查看效果不得把暗骰公开。
- 碎片增加、复制或改变的骰子仍遵守本层万能骰、传染点数和禁忌点数规则。

## 3. 骰子规则

### 对局术语

- **一轮**：从一次叫牌/质疑过程开始，到有人质疑并完成开骰结算为止。
- **一局**：从一组对手进入骰子战斗开始，到玩家或全部对手被淘汰为止；一局包含若干轮。
- **一盘**：从新一轮爬塔开始，到击败最终 Boss 或玩家完全同化结束为止；一盘包含多个节点与多局战斗。

### 基础规则

- 每人 5 颗 d6
- ① 为万能骰子（可当任何点数）
- 叫牌时叫 ① 则 ① 锁定，不再万能
- 每轮首次叫牌的最低数量 = 当前存活人数 + 1；后续可加数量或同数量加点数
- 无斋/飞概念

### 操作

| 操作 | 说明 |
|------|------|
| 加注 | 增加数量，或同数量换更高点数 |
| 质疑 | 质疑上家的叫牌。开骰验证——质疑成功 = 被质疑者感染，质疑失败 = 质疑者感染 |

### 回合顺序

- 庄家在场 → 每轮都由庄家先叫
- 庄家不在场 → 随机先叫
- 之后顺时针轮转

### 骰子数量

无上限约束。卡牌技能可自由增减骰子数。

### 全卡表

#### 普通卡（#1-4）

**#1 · 瘸腿老杰克 —「偷窥」**
每局 1 次，看玩家 1 颗骰子。
| Lv.1 | 看 2 颗 |
| Lv.2 | 看 2 颗，本局可再用一次 |
| Lv.3 | 看 3 颗，可再用一次，看到的骰子对全场公开 |

“对全场公开”表示所有仍存活的 AI 都获得这些骰子的真实情报，并可用于后续叫牌与质疑判断。

**#2 · 锈铁战士 —「意志依存」**
被淘汰时随机给一个存活者 +1 颗 ①。
| Lv.1 | 给两个存活者各 +1 ① |
| Lv.2 | 给两个 + 淘汰前让一个对手 −1 骰子 |
| Lv.3 | 给所有存活者各 +1 ① + 对手 −1 骰子 |

**#3 · 电池小子 —「备用电源」**
第一次被击败免死，回 1 HP。
| Lv.1 | 免死 2 次 |
| Lv.2 | 免死 3 次 |
| Lv.3 | 免死 3 次，每次免死后 +1 骰子 |

**#4 · 信号噪音 —「干扰」**
开局随机禁用玩家 1 个道具。本局生效。
| Lv.1 | 禁用 2 个 |
| Lv.2 | 禁用 3 个 |
| Lv.3 | 禁用 4 个 |

#### 稀有卡（#5-7）

**#5 · 独眼龙 LCD —「锁定」**
每局 1 次，删掉 1 个点数，本局没人能叫。
| Lv.1 | 删 2 个点数 |
| Lv.2 | 删 3 个点数 |
| Lv.3 | 删 3 个点数，被删点数若出现在任何人骰子上 → 随机暴露 1 颗 |

Lv.3 暴露的是一颗原本对其他玩家不可见的普通投骰子，不限于暗骰；暴露后全场知道其点数。

**#6 · 双面人 —「反转骰」** （不升级）
每颗骰子正反面通用，⑥ = 万能骰。

**#7 · 侍从长 —「军械库」**
开局获得 3 个随机道具。
| Lv.1 | 5 个道具 |
| Lv.2 | 5 个道具，保底 1 件稀有以上 |
| Lv.3 | 6 个道具，保底 2 件稀有以上 |

侍从长只会获得并使用作用于自身的战斗道具，不会获得需要指定其他角色为目标的道具，也不会使用金币结算类道具。

#### 史诗卡（#8-12）

**#8 · 回收商 —「捡骰」**
有人开失败时他 +1 骰子。
| Lv.1 | +2 骰子 |
| Lv.2 | +2 骰子，被质疑者也 −1（回收商吸走） |
| Lv.3 | +2，吸 1，每轮结束自动 +1 |

**#9 · 幸运儿 —「骰神眷顾」**
骰子里永远多 1 个 ①。
| Lv.1 | 多 2 个 ① |
| Lv.2 | 多 3 个 ① |
| Lv.3 | 多 3 个，他的 ① 只有他自己能当万能骰 |

| 默认 / Lv.1 | 每场对局最多使用 1 次 |
| Lv.2 | 每场对局最多使用 2 次 |

| Lv.1 | 知道 n−1 人 |

| Lv.1 | 重掷后额外 +1 骰子 |

#### 创世卡（#17）

**#17 · 骰子之神 HOLO —「禁忌变更」** （不升级）

## 5. 抽卡规则与牌堆

### 双牌堆分离

每场战斗分两步抽卡：先抽混合牌堆（含未知），Boss 战再单独抽稀有牌堆。

| 层 | 节点 | 混合牌堆 A | 抽 A | 牌堆 B | 抽 B | 对手数 |
|----|------|-----------|------|--------|------|--------|
| 1 | 普通 | 普通×4 + 未知×1 | 2 | — | — | 2 |
| 1 | Boss | 普通×4 + 未知×1 | 2 | 史诗×5 | 1 | 3 |
| 2 | 普通 | 稀有×3 + 未知×1 | 2 | — | — | 2 |
| 2 | Boss | 稀有×3 + 未知×1 | 2 | 传说×4 | 1 | 3 |
| 3 | 普通 | 史诗×5 + 未知×1 | 2 | — | — | 2 |
| 3 | Boss | 史诗×5 + 未知×1 | 2 | 传说×4 | 1 | 3 |
| 4 | 普通 | 传说×4 + 未知×1 | 2 | — | — | 2 |
| 4 | Boss | 传说×4 + 未知×1 | 2 | 创世×1 | 1 | 3 |

### 规则

- 未知卡每局随机选 1 张注入混合牌堆
- 同稀有度允许重复抽取，同一张卡最多 2 张
- 牌堆 A 和牌堆 B 分开抽取，互不交叉
- 卡牌通过经验等级逐步解锁；抽卡界面只从已经解锁且符合当前牌堆稀有度的卡牌中构建候选。
- 每个牌堆的候选数量从 3 张开始，随符合条件的已解锁卡牌增加，最多展示 5 张；符合条件的已解锁卡牌超过 5 张时，每场随机取最多 5 张供玩家选择。
- 混合牌堆候选仍包含当场注入的 1 张未知卡；候选总数不超过 5，玩家从中选择 2 张。Boss 牌堆独立展示候选并选择 1 张。
- 同场出现重复卡时，每一张卡的角色技能都独立生效；不得因内部只记录一个角色而覆盖另一张重复卡。

### 未知卡触发

## 8. 锈蚀契约·升级

### 经验、解锁与难度

- 经验等级与卡牌/道具解锁系统保留；卡池只能使用已经解锁的卡牌。
- 初始在普通、稀有、史诗、传说四个主要牌池中各解锁 3 张卡；后续经验等级逐步补齐剩余卡牌和道具。
- 不提供独立困难模式或困难模式数值倍率。
- 对手难度提升仅来自玩家在锈蚀工坊购买并启用的卡牌升级等级。
- 参与升级的卡牌均采用五段强化；原本注明“不升级”的卡牌仍不参与锈蚀强化。
- 每张卡购买 Lv.1 至 Lv.5 的费用分别为 1、2、3、4、5 锈蚀点，与稀有度无关；单张卡升满共需 15 点。
- Lv.1 至 Lv.3 沿用该卡原有的逐级技能效果；Lv.3 起追加开局骰子强化：Lv.3 +1 骰、Lv.4 +2 骰、Lv.5 +4 骰。Lv.4、Lv.5 继续保持 Lv.3 技能效果。
- 每次强化的奖励提升不得低于 5%；战斗奖励倍率按照本场实际出现对手的强化等级取平均值：Lv.0 = 1.00、Lv.1 = 1.05、Lv.2 = 1.12、Lv.3 = 1.22、Lv.4 = 1.35、Lv.5 = 1.50。
- 奖励倍率作用于该场战斗的金币与 XP，分别向下取整且至少保留原始奖励；道具数量、道具稀有度和锈蚀点不参与倍率，避免奖励循环失控。

## 12. 同化与死亡

| 次数 | 状态 | 效果 |
|------|------|------|
| 第 1 次 | 半同化 | 画面边缘出现卡牌纹理，继续战斗 |
| 第 2 次 | 完全同化 | 游戏结束。回到主菜单。点数保留。 |

- 半同化状态跨局累积
- 仅能通过净化芯片或事件清除
- 没有二命，没有继承机制

### 半同化诅咒能力

玩家第一次同化并进入半同化时，从以下三种诅咒能力中选择一种。能力随半同化状态跨局保留；通过净化芯片或事件恢复、清除半同化时，已选择的诅咒能力同时消失。

1. **双重万能**：自己的 ③ 也可作为万能骰；持有该能力时，玩家不能叫 ③，也不能叫 ①。
2. **增殖代价**：每轮开始额外增加 1 颗骰子；随后随机选择自己的一颗 ①，将其随机变为 ②～⑥。若当前没有 ①，则本轮只增加 1 颗骰子。
3. **吞噬质疑**：玩家质疑成功时，从被质疑者处吞噬 1 颗骰子并占为己有；玩家质疑失败时立即完全同化，本盘结束。

- 半同化诅咒不是额外生命；玩家再次同化仍会立即完全同化。
- “恢复”仅指净化芯片或事件清除半同化，不包括普通的骰子增加、免疫或其他卡牌技能。
